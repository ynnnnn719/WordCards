# WordCards 單字學習系統

本專案為英文單字學習工具，使用者可以透過單字清單進行單字瀏覽、發音播放及自動複習，協助提升英文單字記憶效率。

## 功能介紹

* 載入單字資料檔
* 顯示英文單字
* 顯示音標
* 顯示中文解釋
* 播放單字發音
* 自動播放單字
* 編輯單字資料
* 顯示目前學習進度
* 使用快捷鍵切換單字
* 儲存修改後的單字資料

## 操作方式

### 單字瀏覽

使用者可從單字清單中選擇單字，系統會顯示：

* 英文單字
* 音標
* 中文解釋

並自動播放對應發音。

### 發音播放

系統會依照單字所設定的音檔路徑播放發音。

若音檔不存在，則於狀態列顯示提示訊息。

### 自動播放模式

按下「Play」按鈕後：

* 系統依序播放單字
* 自動切換至下一個單字
* 播放對應發音

再次按下按鈕即可停止播放。

### 單字編輯

雙擊單字後可開啟編輯視窗。

使用者可修改：

* 單字
* 音標
* 中文解釋
* 音檔路徑

儲存後會更新單字資料檔。

### 快捷鍵操作

| 按鍵    | 功能     |
| ----- | ------ |
| Enter | 下一個單字  |
| Space | 重播目前單字 |
| W     | 上一個單字  |
| S     | 下一個單字  |

## 學習進度

系統會顯示目前瀏覽位置。

例如：
第 35 / 500 個單字

方便使用者掌握目前學習進度。

## 流程

1. 載入 WordCards.txt
2. 建立單字清單
3. 顯示第一個單字
4. 使用者選擇單字或啟動自動播放
5. 系統播放發音
6. 顯示學習進度
7. 可隨時編輯單字內容並儲存
